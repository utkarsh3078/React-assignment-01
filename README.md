How to fetch using api:

1. Make a jsx file in components folder
2. Make a function in that file
3. Make an async function for api calling
4. Go on freeApi website
5. Copy the url to fetch
6. Call Api and do console.log(What it returns on calling it)
7. Now analyze the data came from API
8. Write code to extract the information that we want on our website from the API data.
9. Make return in the end of function and write the html code how the page should look like and How data should be presented on it.
10. Also you can use useEffect for API calling.
